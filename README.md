# AI Chatbot

An AI-driven **Chatbot** that provides solutions using **rules of inference**.  

- The **backend** is implemented in **C++**.  
- The **frontend** is built using **HTML** and **CSS**.  
- Users can **provide premises**, and the chatbot will **derive conclusions** based on logical reasoning.  

This project demonstrates a combination of **logic programming** and a **simple web interface** for interactive problem-solving.
